# おしゃべりの手順書

おしゃべりは、ボタンを押して話しかけた言葉が、ほかの機能のどの言葉にも当てはまらないときに、Claude（Anthropic の会話の AI）で子ども向けの短い返事をして話す機能です（機能の名前は `conversation`）。
機能は `src/osekkai/features/conversation/` にあります。

この手順書は、保護者が鍵を置き、設定を書き、実機で確かめるときに見るものです。

## 1. 何をするか

1. ボタンを押して話しかけると、音声の入口が言葉を聞き取ります（[`docs/voice.md`](voice.md)）
2. どの機能の言葉にも当てはまらないと、おしゃべりが受け取ります。LCD に「ｶﾝｶﾞｴﾁｭｳ」が出ます
3. Claude の返事を、1〜2 文・120 文字までに整えて話します。話す間、LCD に「ﾛｰﾊﾞｰ」が出ます
4. 話し終えたら、続けて聞く待ちになります。待ちの間（既定は 30 秒）にボタンを押すと、前の話の続きとして話せます
5. 押さずに 130 秒たつと、その会話のやりとりを忘れます

決まった言葉で答えて会話を終えるとき:

| とき | 話す言葉 |
| --- | --- |
| 話せる時間帯の外 | いまは ねる じかんだよ。また あした おはなし しようね |
| 時刻が確かでない・鍵がない | いまは おはなし できないんだ。また あとで ね |
| 1 日の上限に達した | きょうは いっぱい おはなし したね。また あした ね |
| インターネットにつながらない | ごめんね、いま インターネットに つながらないみたい |
| Claude が混み合っている | ちょっと つかれちゃった。すこし まってから また はなそうね |
| 時間切れ・そのほかの失敗 | ごめんね、いま うまく かんがえられないみたい |
| 子ども向けでない話 | そのはなしは ちょっと むずかしいな。べつの おはなし しよう |

- 失敗しても、ロボットのほかの機能は動き続けます
- 日課の声かけなど優先度の高い機能が声や画面を使うときは、そちらに譲ります。おやすみモードの間は話しません

## 2. 鍵を置く

Claude を使うには、Anthropic の API の鍵が要ります。鍵は、実機の `~/.config/osekkai/env` に置きます。
このファイルはリポジトリの外にあり、リポジトリには入れません。初期設定（provision）の道具は、このファイルを作らず、中も読みません。

1. 実機で、本人だけが読めるファイルを作ります

   ```sh
   mkdir -p -m 700 ~/.config/osekkai
   touch ~/.config/osekkai/env
   chmod 0600 ~/.config/osekkai/env
   ```

2. エディタで開いて、次の 1 行を書きます。`<ここに鍵>` を自分の鍵に替えます

   ```sh
   ANTHROPIC_API_KEY=<ここに鍵>
   ```

3. ファイルの持ち主がロボットを動かす利用者で、権限が `-rw-------`（0600）であることを確かめます

   ```sh
   ls -l ~/.config/osekkai/env
   ```

   持ち主が違うとき・ほかの人が読み書きできるときは、鍵を使いません（self-check に理由が出ます）。

4. ロボットを起動し直します。鍵は、初めて話しかけたときに 1 回だけ読みます。起動したまま鍵を置いても、起動し直すまで「いまは おはなし できないんだ」のままです。次のコマンドは、おしゃべりを含む版が普段の版として動いているときのものです（サンプルの版が動いているときに行うと、サンプルが止まります）

   ```sh
   systemctl --user restart osekkai.service
   ```

決まり:

- 鍵を、設定ファイル・リポジトリ・チャット・メモなどに書きません
- `ANTHROPIC_LOG=debug` は使いません。Anthropic のライブラリが、送る中身（子どもの言葉）をログに出してしまいます

## 3. 実機に入れる

会話のライブラリ（`anthropic`）は、`rover-deploy deploy` の版の準備で入ります（extras の `pi,voice,conversation,remote`）。自分で入れる必要はありません。
開発 PC と CI には入れません。開発 PC で `pip install -e '.[dev]'` としたときも入りません。

1. 上の 2 章のとおり、鍵を置きます
2. おしゃべりを含む版を `rover-deploy deploy` で入れます
3. self-check で `conversation.setup` が理由なしの「よい」になることを確かめます（6 章）

## 4. 設定の書き方

設定は、基盤と同じ設定ファイル `~/.config/osekkai/config.yaml` の `conversation:` の節に書きます。
見本（[`config/osekkai.example.yaml`](../config/osekkai.example.yaml)）の `conversation:` の節は既定値です。そのままで動きます。
設定を変えたら、ロボットを起動し直します。設定は起動のときに読みます。

```yaml
conversation:
  enabled: true
  call_name: ""
  call_name_variants: []
  hours: ["07:00", "21:30"]
  daily_limit: 60
  max_turns: 10
  reply_timeout_seconds: 20.0
```

| 項目 | 既定値 | 意味 |
| --- | --- | --- |
| `enabled` | `true` | `false` にすると、おしゃべりは開始しません。当てはまらない言葉には、音声の入口が「ごめんね、まだ わからないんだ」と答えます |
| `call_name` | `""` | 子どもの呼び名。返事の中で子どもを呼ぶときに使います。外には送りません（5 章）。空なら「きみ」 |
| `call_name_variants` | `[]` | 聞き取りが書く呼び名の別の形（漢字など）。呼び名と同じく、外に送る前に置き換えます。ひらがなとカタカナの違いは書かなくてよいです |
| `hours` | `["07:00", "21:30"]` | 話せる時間帯（始め、終わり）。始めは含み、終わりは含みません。始めが終わりより後なら、日をまたぐ帯です |
| `daily_limit` | `60` | 1 日に話す返事の数の上限（1〜500）。費用の上限になります（7 章） |
| `max_turns` | `10` | 1 つの会話で覚える往復の数（1〜30）。超えると古い往復から忘れます |
| `reply_timeout_seconds` | `20.0` | 返事を待つ長さ（秒、5〜60）。過ぎたら「ごめんね、いま うまく かんがえられないみたい」と話します |

- 時刻は `"07:00"` のように、引用符で囲みます。秒とタイムゾーンは書けません。始めと終わりを同じにすることはできません。止めたいときは `enabled: false` にします
- 呼び名は個人の情報です。見本の値は空のままにし、実機の設定ファイルにだけ書きます
- 設定に誤り（範囲の外、時刻の書き方の誤りなど）があると、おしゃべりは開始しません。ほかの機能は動きます。誤りの場所（キーのパス）と理由はログに、誤りの件数は self-check の `core.config` に出ます。値は出しません

## 5. データの扱い

Claude に送るもの:

- 子ども向けの決まりの文（話し方の決まり）
- その会話のやりとり（子どもの言葉と、前の返事）。呼び名とその別の形は、送る前に目印に置き換えます

送らないもの:

- 子どもの呼び名
- 声（録音）。声は実機の中で文字にします
- 日付・場所・顔の記録など、ほかの機能のデータ

残すもの・残さないもの:

- 実機に残すのは、その日の返事の回数だけです（`~/.local/state/osekkai/conversation/usage.json`。日付と回数）
- 会話のやりとりは記憶の中にだけ置きます。会話が終わって 130 秒たつと忘れます。ロボットを止めても消えます
- 返事の音声は、話し終えたら残しません
- 子どもの言葉・返事・呼び名・鍵は、ログ・self-check の結果・記録に出しません。ログには決まった文言・回数・かかった時間・誤りの種類の名前だけを出します
- Anthropic の側でのデータの扱いは、Anthropic の利用規約とプライバシーの方針に従います

## 6. self-check の項目

`python -m osekkai --self-check`（実機では `rover-deploy self-check`）に、`conversation.setup` が出ます。
鍵がなくても「だめ」にはしません（版を戻しても直らないため）。「よい」に理由を添えて知らせます。

| 結果 | 理由 | 直し方 |
| --- | --- | --- |
| よい | （なし） | 鍵を使えます |
| よい | 鍵のファイルがない | 2 章のとおり、`~/.config/osekkai/env` を作ります |
| よい | 鍵のファイルを本人だけが読めるようにしていない | `chmod 0600 ~/.config/osekkai/env` を行い、持ち主を確かめます |
| よい | 鍵が書かれていない | `ANTHROPIC_API_KEY=` の行と値を書きます |
| よい | 鍵のファイルを読めない | ファイルの種類と文字コード（UTF-8）を確かめます |
| 飛ばした | 無効 | 設定で `enabled: false` のときです |
| 飛ばした | おしゃべりの設定を使えない | 設定ファイルがないか、誤りがあるときです。`core.config` を見ます |
| 飛ばした | 会話のライブラリがない | 開発 PC と CI ではこれになります。実機で出たら、版の準備（`rover-deploy deploy`）をやり直します |

鍵を直したら、ロボットを起動し直します（2 章の 4）。

## 7. 費用の目安

返事 1 回で、入力が約 1,000 トークン、出力が約 300 トークンです。1 回の費用は約 1 円です。
既定の上限（1 日 60 回）まで話しても、1 日に約 60 円です。決まりの文はキャッシュに入るので、実際はこれより少なくなります。
上限に達した日は、それ以上 Claude に問い合わせません。日付が変わると 0 から数えます。
回数の記録が壊れて読めない日は、上限に達したとみなして、その日は話しません（費用を守るため）。

費用を抑えたいときは `daily_limit` を小さくします。使った額は Anthropic の管理画面で確かめます。

## 8. 実機で確かめる

子どもが使う前に、保護者が実機で次を確かめます。

1. self-check で `conversation.setup` が理由なしの「よい」になる
2. ボタンを押して、どの機能にも当てはまらない言葉（例: 「そらは どうして あおいの」）を話すと、LCD に「ｶﾝｶﾞｴﾁｭｳ」が出てから、短い返事を話す
3. 話し終えた後、続けて聞く待ちの間にボタンを押して続きを話すと、前の話につながった返事をする
4. 返事の中で、呼び名で呼ばれる（`call_name` を書いたとき）
5. 日課の言葉など、ほかの機能の言葉は、これまでどおりその機能が答える
6. 実機のネットワークを切って話すと「ごめんね、いま インターネットに つながらないみたい」と話し、ロボットは動き続ける
7. 時間帯の外に話すと「いまは ねる じかんだよ。また あした おはなし しようね」と話す
8. ログ（`journalctl --user-unit=osekkai.service -b`）に、話した言葉・返事・呼び名・鍵が出ていない

## 9. PC で試す（ハードなし・鍵なし）

開発 PC では、会話のライブラリと鍵がなくても試せます。ハードなしで動かすと、Claude の代わりに決まった返事を順に返し、端末に出します。開発 PC に会話のライブラリと本物の鍵を置いていなければ、外には何も送りません。

```sh
python -m osekkai --fake-hardware
```

端末で、どの機能にも当てはまらない言葉を打って Enter を押すと、決まった返事が出ます。
