# ラジコンの手順書

ラジコンは、家の Wi-Fi の中のスマホやタブレットのブラウザから、ロボットを走らせて遊ぶ機能です（機能の名前は `remote`）。
ボタンを押している間だけ走ります。首を動かし、ブッブーやダンスをし、2 台のカメラの映像を見て、写真を撮り、入れた文字をロボットに話させます。
機能は `src/osekkai/features/remote/` にあります。

この手順書は、保護者がラジコンを使えるようにするとき、止まる距離を部屋に合わせるとき、実機で確かめるときに見るものです。

## 1. 前提

- ラジコンの依存（Web の部品の flask）は、`rover-deploy deploy` の版の準備で入ります（extras の `pi,voice,conversation,remote`）。自分で入れる必要はありません。ラジコンを含む版を入れます（[`docs/deploy.md`](deploy.md)）
- 家の Wi-Fi の中だけで使います。家の外のアドレスからの要求は断ります。家の外から開けるように、ルーターのポートを開けないでください
- 通信は暗号化しません（HTTPS ではありません）。pin は家のネットワークの中を暗号化されずに流れます。家の Wi-Fi に、知らない人をつながないでください
- 既定では無効です。2 章のとおりに有効にするまで、待ち受けません

## 2. 使えるようにする

1. 実機の設定ファイル `~/.config/osekkai/config.yaml` の `remote:` の節に、次のように書きます

   ```yaml
   remote:
     enabled: true
     pin: "123456"
   ```

   - pin は、引用符で囲んだ 4〜8 けたの数字にします。6 けた以上をすすめます。上の `"123456"` は見本です。家で決めた数字に変えます
   - 引用符のない数（`pin: ` のあとに数字だけ）は、pin がないものとして扱います。待ち受けず、self-check の `remote.setup` が「だめ」になります。YAML は、引用符のない数の先頭の 0 を消したり、8 進の数として読んだりするからです
   - pin は実機の設定ファイルだけに書きます。リポジトリ・設定の見本（[`config/osekkai.example.yaml`](../config/osekkai.example.yaml)）・コミットには入れません
2. ロボットを起動し直します。設定は起動のときに読みます

   ```sh
   systemctl --user restart osekkai.service
   ```

3. self-check で `remote.setup` が理由なしの「よい」になることを確かめます（7 章）

## 3. 開き方

スマホやタブレットを家の Wi-Fi につないで、ブラウザで次のどちらかを開きます。

- `http://<ロボットの名前>.local:8080/`（`<ロボットの名前>` は実機のホスト名）
- `http://<ロボットの家のアドレス>:8080/`（ルーターが渡した、家の中の IP アドレス）

`8080` は設定の `port` です。変えたときは、その数にします。

開ける宛先の名前は、次のどれかだけです（DNS リバインディングへの備え）。ほかの名前で開くと断ります。

- 家のネットワークの IP アドレス（IPv4 のプライベートアドレス、IPv6 のユニークローカルとリンクローカル）
- `localhost` とループバックのアドレス
- 点のない 1 つの名前（数字だけの名前は除く）
- `.local` で終わる名前

## 4. 遊び方

### ログイン

1. pin を入れる画面が出ます。pin を入れると、操作の画面になります
2. まちがえると「ばんごうが ちがうよ」と出ます
3. まちがいが 5 回続くと、5 分間、どの端末からも pin を確かめません。「しばらく まってね」と出ます。正しい pin でログインできると、まちがいの数は 0 に戻ります
4. ログインは 12 時間で切れます。ロボットを起動し直したときも切れます。pin を入れ直します
5. 「おわる」を押すと、ログインを切って pin の画面に戻ります

### 操作

- 走る: 前・左前・右前・後ろ・左後ろ・右後ろの 6 つのボタンがあります。押している間だけ走ります。離す・「とめる」を押す・画面を隠す・写真を撮ると止まります。命令が 0.5 秒届かないときも止まります
- 速さ: 「ゆっくり」と「はやい」から選びます。始めは「ゆっくり」です
- 首: 上・下・左・右で 15 度ずつ動き、「まんなか」で正面に戻ります
- ブッブー: 「ブッブー！」などを 1 つ話します。ほかの言葉を話している途中なら、話しません
- ダンス: 首だけで踊ります。タイヤは動きません。走るボタンを離す・「とめる」を押すと、次の動きの前に止まります
- 写真: 走行を止め、「はい、チーズ！」と話してから、使えるカメラで 1 枚ずつ撮ります。撮れたら「とれたよ！」と話し、端末に写真を出します。端末に保存できます
- 話させる: 文字を入れて送ると、ロボットが話します。120 文字までです。ほかの言葉を話している途中なら「いま おはなし ちゅう。ちょっと まってね」と出ます
- 映像: 首のカメラと USB カメラの映像が出ます。同じカメラを同時に見られるのは 3 台までです。使えないカメラの枠には「カメラが つかえないよ」と出ます

### 操作する端末は 1 台

- ログインした端末のうち、最初に操作した 1 台だけが操作できます。ほかの端末には「いまは ほかの ひとが そうさ ちゅう」と出ます。映像は見られます
- 操作する端末の最後の操作から 10 秒たつと、ほかの端末が操作できるようになります。そのとき走行は止まります

## 5. 安全の決まり

### 前に進むとき

- 前の物までの距離と前の床の段差を、0.1 秒ごとに確かめます
- 前の物が `stop_cm`（既定は 20 cm）より近いと、すぐ止まります。「おっと、なにか あるよ」と話し、画面に「まえに なにか あるよ」と出ます
- 床の 3 つの値のどれかが `cliff_reference`（既定は 500）以下だと、段差として止まります。「あぶない！とまるよ」と話し、画面に「だんさが あるよ！」と出ます
- 危険が続いている間は、前に進みません。後退はできます
- 止まったときの声は 10 秒に 1 回までです。画面の知らせは毎回出ます
- センサーを読めないとき（故障・読み取りの失敗・ありえない値）は、危険として前に進みません。ロボットが起動した直後の約 2 秒は、床を読めないので前に進みません。これはふつうです

### 後退

- 後ろはセンサーで確かめられません。後退は、選んだ速さにかかわらず「ゆっくり」で走ります
- 後ろのボタンを押し続けて `back_max_seconds`（既定は 2 秒）たつと止まります。ボタンを離して、もう一度押すと、また下がります
- 後退のボタンの近くに「うしろは みえないよ。ゆっくり さがるよ」と出ます

### 使える時間とほかの機能

- 使える時間帯（`hours`、既定は 07:00〜20:00）の外とおやすみモードの間は、操作できません。「いまは ラジコンの じかんじゃないよ」と出ます。操作の途中で時間帯が終わったときも、すぐ止まります
- ロボットの時刻が確かでないときは、操作できません。「いまは つかえないよ」と出ます
- 1 日に使える時間の上限はありません
- 日課・音声の入口（話しかけ）・おしゃべり・だるまさんが始まると、ラジコンはすぐに走行・ダンス・首を止めて譲ります。「ローバーは いま ほかの ことを しているよ。ちょっと まってね」と出ます。終わった後に操作すると、また使えます（止まる前の操作は続けません）
- ラジコンは、見つけてあいさつより先に首を使います。首のカメラの映像を見ている間は、見つけてあいさつが首を動かしません

## 6. 設定の書き方

設定は、基盤と同じ設定ファイル `~/.config/osekkai/config.yaml` の `remote:` の節に書きます。
見本（[`config/osekkai.example.yaml`](../config/osekkai.example.yaml)）の `remote:` の節は既定値です。pin は書いてありません。
設定を変えたら、ロボットを起動し直します。

| 項目 | 既定値 | 意味 |
| --- | --- | --- |
| `enabled` | `false` | `true` にすると、ラジコンを待ち受けます |
| `pin` | なし | ログインの番号。引用符で囲んだ 4〜8 けたの数字（6 けた以上をすすめます）。実機の設定ファイルだけに書きます |
| `port` | `8080` | 待ち受けるポート（1024〜65535） |
| `hours` | `["07:00", "20:00"]` | 使える時間帯（始め、終わり）。始めを含み、終わりを含みません。時刻は引用符で囲みます。始めが終わりより後なら、日をまたぐ帯です。始めと終わりを同じにはできません |
| `speed_slow` | `20` | 「ゆっくり」の速さ（1〜100）。後退はいつもこの速さです |
| `speed_fast` | `35` | 「はやい」の速さ（`speed_slow` 以上、100 まで） |
| `stop_cm` | `20.0` | 前の物がこれより近いと止まる（cm、5〜100） |
| `cliff_stop` | `true` | 床の段差で止まるか。`false` にすると、前の物の距離だけで止まります |
| `cliff_reference` | `500` | 床の値がこれ以下なら段差（0〜4095） |
| `back_max_seconds` | `2.0` | 後退を続けられる長さ（秒、0.5〜10） |
| `photo_days` | `30` | 写真を残す日数（1〜365） |
| `usb_camera` | `""` | USB カメラの道（`/dev/` で始める）。空なら C270 を自動で探します |

- 設定に誤り（範囲の外など）があると、ラジコンは開始しません。ほかの機能は動きます。誤りの場所（キーのパス）と理由はログに、誤りの件数は self-check の `core.config` に出ます。値は出しません
- pin が使えないとき（ない・引用符のない数・4〜8 けたの数字でない）は、設定の誤りにはせず、待ち受けないだけにします。理由はログと self-check の `remote.setup` に出ます

## 7. self-check の項目

`python -m osekkai --self-check`（実機では `rover-deploy self-check`）に、次の 3 つの項目が出ます。

| 項目 | 確かめること |
| --- | --- |
| `remote.setup` | pin とポートの設定が使えるか、Web の部品があるか |
| `remote.sensors` | 前の物の距離と床の段差を読めるか（ロボットが動いているときは飛ばします） |
| `remote.usb_camera` | USB カメラがあるか |

| 結果 | 理由 | 直し方 |
| --- | --- | --- |
| よい | （なし） | 使えます |
| 飛ばした | 無効 | `enabled: false` のときです |
| 飛ばした | ラジコンの設定を使えない | 設定ファイルがないか、誤りがあるときです。`core.config` を見ます |
| だめ | 設定に誤りがあります | `remote:` の節を直します。場所と理由はログに出ます |
| だめ | pin は引用符で囲んだ 4〜8 けたの数字にしてください | 2 章のとおりに pin を書きます |
| だめ | Web の部品（flask）がありません | ラジコンを含む版を `rover-deploy deploy` で入れ直します |
| だめ | ポートを使えません | ほかのプログラムがそのポートを使っています。`port` を変えます |
| 飛ばした | センサーのライブラリがない | 開発 PC と CI ではこれになります |
| だめ | センサーを読めません | センサーのケーブルを確かめます。8 章の道具で値を見ます |
| だめ | USB カメラが見つかりません | USB カメラを差し直します。`usb_camera` に道を書いたときは、その道を確かめます |

- ポートは、ロボットが止まっているときだけ確かめます（動いているときは、ラジコンがポートを使っています）
- `remote.sensors` は床を読めるまで約 2 秒待つので、少し時間がかかります
- 理由には、pin・端末のアドレス・話させた文字を出しません

## 8. センサーを確かめる道具

止まる距離と段差の判定が部屋に合っているかを、実機で確かめます。道具はタイヤを動かしません。
ロボットのサービスを止めてから動かします。動いたままだと「ロボットが動いています。止めてから実行してください」と出て、終了コード 75 で終わります（センサーに触りません）。

```sh
systemctl --user stop osekkai.service          # 1. サービスを止める
cd ~/osekkai-rover/current
.venv/bin/python -m osekkai.features.remote --sensor-test --seconds 30   # 2. 道具を動かす
systemctl --user start osekkai.service         # 3. 終わったらサービスを起動する
```

0.5 秒ごとに、次のような行が出ます。

```text
距離 35.2 cm  床 1320 1290 1410  段差なし  ふつう
距離 9.9 cm  床 1310 1280 1400  段差なし  まえに なにか
距離 遠い  床 210 1300 1390  段差あり  だんさ
```

| 列 | 意味 |
| --- | --- |
| 距離 | 前の物までの距離。何もないときは「遠い」、読めないときは「読めない」 |
| 床 | 床のセンサーの 3 つの値（0〜4095）。読めないときは「読めない」 |
| 段差 | 設定の `cliff_reference` での判定。「段差あり」「段差なし」。`cliff_stop: false` なら「判定しない」 |
| 判定 | 走るときと同じ判定。「ふつう」「まえに なにか」「だんさ」「読めない(危険)」 |

- 始めの約 2 秒は、床が「読めない」、判定が「読めない(危険)」になります。これはふつうです
- 実機で見た値の目安: 床の上で床の値は 1230〜1500 くらい、手を 10 cm に置くと距離は 9.9 cm くらいでした
- 止まる距離を合わせる: 止まってほしい距離に物を置いて距離を見ます。その距離より少し大きい値を `stop_cm` に書きます
- 段差の判定を合わせる: 床の上の値と、机の端から床のセンサーを外に出したときの値を見ます。その間の値を `cliff_reference` に書きます。床の上の値より十分小さくします（床の色が暗いと値は小さくなります）
- 書いたら、もう一度道具で確かめます

使い方:

```text
python -m osekkai.features.remote --sensor-test [--seconds N] [--fake-hardware] [--config PATH]
```

| 指定 | 意味 |
| --- | --- |
| `--sensor-test` | センサーを確かめます（必ず付けます） |
| `--seconds N` | 確かめる秒数（1〜600 の整数。既定は 30） |
| `--fake-hardware` | 実機の代わりに、いつも安全な偽のセンサーを使います（PC で確かめる） |
| `--config PATH` | 設定ファイルを指定します |

- `enabled: false` のままでも動きます。使えるようにする前に、止まる距離を確かめられます
- 途中で Ctrl+C で止めても大丈夫です

終了コード:

| コード | 意味 |
| --- | --- |
| 0 | 確かめ終えた（Ctrl+C で途中で止めたときも） |
| 1 | センサーを使えない・設定の誤り |
| 2 | 指定の誤り |
| 75 | ロボットが動いている（止めてから実行します） |

## 9. データの扱い

- 写真は、実機の `~/.local/share/osekkai/remote/photos/` に保存します（`XDG_DATA_HOME` を変えたときは、その下の `osekkai/remote/photos/`）。保護者だけが読めるようにします（ディレクトリは 0700、ファイルは 0600）
- 写真の名前は、撮った時刻とカメラが分かる名前です（例: `20261108-153000-00-neck.jpg`）
- `photo_days`（既定は 30 日）たった写真は、1 日に 1 回とロボットの起動のときに消します
- 端末の画面には、写真の一覧を出しません。端末から消すこともできません。端末に返すのは、そのとき撮った写真だけです。前の写真は、実機の保存先から取り出します
- 映像は保存しません。話させた文字は、ログにも記録にも残しません
- pin・入れられた pin・端末のアドレス・話させた文字は、ログと self-check の結果に出しません

## 10. 困ったとき

| ようす | 見ること |
| --- | --- |
| ページが開かない | `enabled: true` か、pin が引用符で囲んだ数字か（self-check の `remote.setup`）。スマホが家の Wi-Fi につながっているか。`.local` の名前で開けないときは、家のアドレスで開きます |
| 開くと断られる | 3 章の名前のどれかで開いているか。家の外のアドレスからは開けません |
| 「しばらく まってね」と出る | まちがいが 5 回続きました。5 分待ちます |
| 「いまは ラジコンの じかんじゃないよ」と出る | 使える時間帯（`hours`）の外か、おやすみモードです |
| 「いまは つかえないよ」と出る | ロボットの時刻が確かでありません。ネットワークにつながって時刻が合うまで待ちます |
| 「いまは ほかの ひとが そうさ ちゅう」と出る | ほかの端末が操作しています。その端末の操作から 10 秒たつと操作できます |
| 「ローバーは いま ほかの ことを しているよ」と出る | 日課や話しかけなどが動いています。終わるのを待ちます |
| 前に進まない | 危険か、センサーを読めていません。8 章の道具で値を見ます。起動の直後の約 2 秒は進みません |
| 後ろに下がり続けない | 後退は `back_max_seconds`（既定は 2 秒）で止まります。ボタンを離して押し直します |
| カメラの枠に「カメラが つかえないよ」と出る | 首のカメラは、見つけてあいさつが動いていて、ほかの機能が使っていないときだけ見られます。USB カメラは self-check の `remote.usb_camera` を見ます |
| 「いまは みられないよ」と出る | 同じカメラを 3 台の端末で見ています |

ログは `journalctl --user-unit=osekkai.service -b` で見ます。待ち受けないときは「ラジコンを始めません: 」に続けて理由が出ます。

## 11. PC で試す（ハードなし）

開発 PC では、偽のハードで画面を開いて操作できます。

1. Web の部品も入れます

   ```sh
   pip install -e '.[dev,remote]'
   ```

2. PC の設定ファイルに、2 章と同じように `enabled: true` と pin を書きます
3. ハードなしで動かします

   ```sh
   python -m osekkai --fake-hardware
   ```

4. ブラウザで `http://localhost:8080/` を開きます

- センサーは、いつも安全な偽物を使います。危険では止まりません
- 走行・首・LCD・話す言葉は、端末に出ます
- カメラがなければ、カメラの枠に「カメラが つかえないよ」と出ます

## 12. 実機で確かめる

子どもが使っていない時間に、保護者が実機で確かめます。Android と iPhone の両方で行います。

1. self-check で `remote.setup`・`remote.sensors`・`remote.usb_camera` が理由なしの「よい」になる（`remote.sensors` はサービスを止めて確かめる）
2. 8 章の道具で、床の値と、手を置いたときの距離が出る。合わなければ `stop_cm` と `cliff_reference` を直す
3. ページを開いて、pin でログインできる。まちがえると「ばんごうが ちがうよ」と出る
4. 前・左前・右前・後ろ・左後ろ・右後ろで、押している間だけ走る。離すと止まる。「とめる」で止まる
5. 後ろを押し続けると、ゆっくり下がって 2 秒で止まる。離して押し直すと、また下がる
6. 首の上・下・左・右を押すと、首のカメラの映像がその向きに動く（逆なら記録して直す）。「まんなか」で正面に戻る
7. ダンスで首だけで踊る。タイヤは回らない。「とめる」で止まる
8. 写真を撮ると、「はい、チーズ！」「とれたよ！」と話し、端末に写真が出て保存できる。実機の保存先に写真がある
9. 文字を送ると、ロボットが話す
