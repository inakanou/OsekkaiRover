# 見つけてあいさつの手順書

見つけてあいさつは、首のカメラで顔を見つけて、首と待機画面の目で追い、あいさつする機能です（機能の名前は `presence`）。
覚えた顔なら、呼び名であいさつします。知らない顔には、呼び名を入れずにあいさつします。

この手順書は、保護者が顔を覚えさせるときと、設定を変えるとき、困ったときに見るものです。

## 1. 動き方

- 顔を 1 秒見つけ続けると、LCD に「♥ ﾐﾂｹﾀ! ♥」を出してから、あいさつします
- 朝（11 時より前）にその日はじめて見つけたら「おはよう、{呼び名}！きょうも よろしくね」
- 120 分以上見えなかった後は「{呼び名}、おかえり！まってたよ」
- そのほかは「あ、{呼び名}だ！」などのどれか。同じ人には、20 分見えなかった後でないと、またあいさつしません
- あいさつは 7 時から 20 時 30 分の間だけです。その外でも、顔を見つけて首で追うことは続けます
- 日課などほかの機能が首・声・画面を使うときは、すぐに見るのをやめて返します。おやすみモードの間は、カメラを止めて何もしません
- 時刻が確かでない間は、あいさつしません

## 2. コマンドを動かす前に

顔を覚える・消す・確認のコマンドは、ロボットのサービスを止めてから、実機で動かします。
動いたままだと「ロボットが動いています。止めてから実行してください」と出て、終了コード 75 で終わります（何もしません）。

実機にログインして、次の順に行います。

```sh
systemctl --user stop osekkai.service          # 1. サービスを止める
cd ~/osekkai-rover/current
.venv/bin/python -m osekkai.features.presence --list   # 2. コマンドを動かす（例は一覧）
systemctl --user start osekkai.service         # 3. 終わったらサービスを起動する
```

- 子どもが使っていない時間に行います
- 覚えた人の一覧（`--list`）だけは、サービスが動いたままでも使えます
- 以下のコマンドは、`~/osekkai-rover/current` で `.venv/bin/python -m osekkai.features.presence` に続けて書きます

## 3. 顔を覚える

```sh
.venv/bin/python -m osekkai.features.presence --learn-face child --call-name <よびな>
```

- `--learn-face` の後は、その人の名前（識別子）です。a-z で始まり、a-z・0-9・`_` だけの 32 文字までです（例: `child`）
- `--call-name` の後は、ロボットが話すときの呼び名です。読みまちがえないように、ひらがなで書くのが確実です
- 始めると、ロボットが「〇〇の おかおを おぼえるよ。ローバーの ほうを みてね」と話し、LCD に集めた数（例: `ｵﾎﾞｴﾃﾙﾖ 12/40`）が出ます
- 40 秒の間、顔を集めます。途中で「こんどは すこし よこを むいてみて」と言うので、少し横を向きます
- 10 個以上集まれば保存して「おぼえたよ！これからは 〇〇って よぶね」と話します（終了コード 0）
- 足りなければ何も保存せず「うまく おぼえられなかった。あかるい ところで もういちど やってみてね」と話します（終了コード 1）。明るい場所で、もう一度行います
- 同じ名前でもう一度覚えると、前の顔は置き換わります。呼び名を変えたいときも、同じ名前でもう一度覚えます
- 設定で `presence.enabled: false` のときは、覚えません（終了コード 1）

## 4. 一覧・消す

```sh
.venv/bin/python -m osekkai.features.presence --list                # 覚えた人の名前と見本の数
.venv/bin/python -m osekkai.features.presence --forget-face child   # 1 人の顔とあいさつの記録を消す
.venv/bin/python -m osekkai.features.presence --forget-all          # すべての顔とあいさつの記録を消す
```

- 一覧には名前（識別子）と見本の数だけが出ます。呼び名は出ません
- 覚えていない名前を `--forget-face` に書くと「その名前の顔は覚えていません」と出ます（終了コード 2）。`--list` で名前を確かめます
- 「覚えた顔を読めません」と出たときは、保存したファイルが壊れています。`--forget-all` ですべて消してから覚え直すか、バックアップから戻します（[`deploy.md`](deploy.md) の「バックアップから戻す」）。覚える・1 人を消すは、ほかの人の顔を黙って消さないように、始めません

## 5. 確認のコマンド

カメラの向きや追い方を確かめるときに使います。どちらも端末に出すだけで、何も保存しません。

```sh
.venv/bin/python -m osekkai.features.presence --watch-test                # 追従の確認（30 秒）
.venv/bin/python -m osekkai.features.presence --motion-test --seconds 60  # 動きの量の確認（60 秒）
```

- `--watch-test`: 顔の位置・首の角度・目の向き・認識の結果を出し続けます。認識の結果は「覚えた人」「知らない人」「まだ」（顔は見えているが、まだ分からない）「-」（顔が見えていない）だけで、名前は出ません。既定は 30 秒です
- `--motion-test`: 2 秒ごとに動きの量（0〜1）を出します。既定は 20 秒です
- `--seconds` で秒数を変えられます（1〜3600）。途中で Ctrl+C で止めても大丈夫です
- 首が顔と逆に動くとき、目の向きが逆のとき、映像が上下逆のときは、次の設定の反転を使います

## 6. 設定

設定は、基盤と同じ設定ファイル `~/.config/osekkai/config.yaml` の `presence:` の節に書きます。
見本（[`config/osekkai.example.yaml`](../config/osekkai.example.yaml)）の値は、すべて既定値です。書いていない項目は既定値になります。
設定を変えたら、ロボットを起動し直します。設定は起動のときに読みます。

| 項目 | 既定値 | 意味 |
| --- | --- | --- |
| `enabled` | `true` | `false` にすると、見つけてあいさつは開始しません |
| `greet_hours` | `["07:00", "20:30"]` | あいさつする時間帯（始め、終わり）。始めの時刻を含み、終わりの時刻は含みません。始めを終わりより後にすると、日をまたぐ帯になります |
| `away_minutes` | `20` | この分だけ見えなかったら、またあいさつします（1〜600） |
| `okaeri_minutes` | `120` | この分だけ見えなかったら「おかえり」にします（1〜1440。`away_minutes` 以上） |
| `morning_end` | `"11:00"` | この時刻より前なら、朝のあいさつにします |
| `match_threshold` | `0.38` | 覚えた顔と似ているかのしきい値（0〜1）。大きくすると、ほかの人とまちがえにくくなり、本人でも分かりにくくなります |
| `pan_reverse` | `false` | 首の左右の動きを反転します |
| `tilt_reverse` | `false` | 首の上下の動きを反転します |
| `gaze_reverse` | `false` | 待機画面の目の向きを反転します |
| `flip` | `false` | 映像の上下（180 度）を反転します |

- 時刻は `"07:00"` のように、必ず引用符で囲みます。秒とタイムゾーンは書けません
- 設定に誤りがあると、見つけてあいさつは開始しません（ほかの機能は動きます）。誤りの場所と理由がログに出ます

## 7. 使えるかを確かめる（self-check）

self-check に、次の 3 つの項目が出ます（実機で `~/osekkai-rover/current/.venv/bin/python -m osekkai --self-check`。開発 PC からは `rover-deploy self-check`）。

| 項目 | 確かめること | だめのときの理由 |
| --- | --- | --- |
| `presence.camera` | 首のカメラが見つかるか | カメラが見つからない |
| `presence.models` | 顔の検出と認識のモデルのファイルがあるか（初期設定が `~/.local/share/osekkai/models/` に置きます） | 顔のモデルがない |
| `presence.faces` | 覚えた顔が読めるか | よいのまま「覚えた顔を読めない」を添えます。4 の手順で直します |

- カメラのライブラリがない開発 PC では、`presence.camera` と `presence.models` は「カメラのライブラリがない」で飛ばします
- 無効のとき・設定を使えないときは、3 つとも飛ばします
- カメラやモデルが使えなくても、ロボットのほかの機能は動き続けます

## 8. 個人データの扱い

- **顔の画像は保存しません。** 保存するのは、顔の特徴（数字の並び）と呼び名だけです
- 覚えた顔は `~/.local/state/osekkai/presence/faces.json`、あいさつの記録（最後に見た時刻・朝のあいさつをした日）は同じ場所の `greetings.json` に置きます。どちらも本人だけが読める権限です
- 顔の特徴と映像は、外部に送りません
- ログ・self-check・一覧の表示に、呼び名・顔の特徴・あいさつの言葉は出ません
- 呼び名は、顔を覚えるコマンドでだけ指定します。リポジトリや設定の見本には書きません。コマンドの履歴（`~/.bash_history`）に残るので、気になるときは履歴から消します

### すべて消すとき

1. サービスを止めて、`--forget-all` を実行します。退避された壊れたファイル（`faces.corrupt-*.json` など）も消します
2. 実機の入れ替えのバックアップ（[`deploy.md`](deploy.md) の「バックアップ」）には、記録（`state/`）として覚えた顔も入ります。実機の `~/.local/state/osekkai-deploy/backups/` と、開発 PC の `backup_dir`（既定は `~/.local/share/osekkai-deploy/backups`）の、消す前のバックアップを消します
3. 機能ごと使わないときは、設定で `presence.enabled: false` にします
