# Product Overview

OsekkaiRover（おせっかいローバー）は、家庭で暮らしに寄り添う**仕事や生活の補佐役**のロボットです。SunFounder PiCar-X（Raspberry Pi 5）の上で動きます。最初の領域は、**子ども（4 歳前後）の生活習慣づくりと遊びのサポート**です。ここから、家族の仕事や生活を手伝う機能を少しずつ足していきます。

使う人:
- **子ども**: 声をかけられ、ボタンや声で応え、ほめられ、一緒に遊ぶ
- **保護者**: 時刻・名前・使える時間を決める。安全と個人データの扱いを任せられることを求める
- **開発者**（保護者が兼ねる）: 機能を足し、実機に入れる

## Core Capabilities
- **暮らしのリズムを支える**: 決まった時刻に声をかけ、できたらほめて星をためる。夜はおやすみモードで静かにする
- **気づいて関わる**: 顔を見つけて首を向け、覚えた顔なら名前であいさつする
- **話しかけられる入口**: ボタンを押して話すと、言葉に合う機能が応える。当てはまらなければおしゃべりで返す
- **一緒に遊ぶ**: だるまさんがころんだ、スマホのラジコン
- **機能を足していける**: 新しい補佐機能は、基盤の「機能を足す口」に登録するだけで、声・画面・動き・音声の入口を使える

## Target Use Cases
- 朝の支度・歯みがき・寝る準備を、叱らずに子どもが自分から進められるようにする
- 帰ってきた子どもを迎え、話し相手や遊び相手になる
- 保護者が、家の Wi-Fi の中で、時間を決めて子どもにラジコンで遊ばせる
- 今後: 家族の予定・家事・仕事の補佐を、同じ音声の入口から呼び出す

## Value Proposition
- **やさしい関わり方**: 叱らず、短く、ほめて続けさせる。催促の回数には上限がある。できなくても責めない
- **家の中で完結する安心**: 子どもの名前・顔・声・記録を外に出さず、残さない。外部（Claude API）に送るのは会話の文字だけで、名前は送らない
- **安全を最優先**: 止めるときは必ずモーターを止める。命令が途切れたり危険を検知したりしたら止まる。走るのは許可した場面だけ
- **夜は静か**: おやすみモード、時間帯の制限、暗い再起動
- **育てていけるロボット**: 機能を足しても基盤を書き換えない。PC で確かめてから実機に入れる

## Product Principles
機能の要件と設計で迷ったときは、この順に優先します。
1. **子どもの安全**（動き・音量・夜間）
2. **個人データの保護**（保存しない・外に出さない・消せる）
3. **毎日の習慣を壊さない**（日課の声かけを、ほかの機能より優先する）
4. **楽しさと使いやすさ**
