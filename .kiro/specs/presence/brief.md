# Brief: presence

## Problem
子どもは、ロボットが自分に気づいてくれると嬉しい。帰ってきたら「おかえり！」、朝は名前を呼んで「おはよう」と言ってほしい。保護者は、顔の画像を保存せず、覚えた顔の情報をいつでも消せることを求めている。

## Current State
サンプルの `watcher.py` と `routine.py` の一部に、次の振る舞いがある。
- **顔の検出**:
  - 首のカメラ（picamera2）で、YuNet（OpenCV Zoo）を使って顔を検出する
  - YuNet がなければ、精度の低い Haar 検出に切り替える
- **首と目の追従**:
  - 首（パンとチルト）を顔の方向へ向け、LCD の目もそちらを見る
  - 向きの反転は設定で切り替える
- **顔の認識**:
  - SFace で顔の特徴を数字にして、覚えた顔と比べる
  - 直近の 3 回のうち 2 回一致したら、本人と判断する
- **顔の登録**:
  - 約 30〜40 秒、ロボットを見てもらって特徴を集め、保存する
  - 削除もできる
  - 写真ではなく特徴（数字）だけを保存する
- **あいさつ**:
  - しばらく（既定 20 分）見えなかった人が来たら、あいさつする
  - 朝（11 時前）の最初は「おはよう」、長く（120 分）いなかったら「おかえり」
  - 名前で呼ぶのは、覚えた顔のときだけ
  - あいさつする時間帯を、設定で決める
- **カメラを止める**: タスク中・ラジコン中・おやすみモード中は止める
- **ほかの機能への提供**: 動きの量（だるまさん用）と静止画・映像（ラジコン用）

見つかっている問題:
- 知らない人が全員、1 つの「朝のあいさつ済み」を共有している
- 首のサーボを、ほかの機能と取り合っている

## Desired Outcome
- 子どもから見た振る舞い（見つけて首を向ける、名前を呼んであいさつする）はサンプルと同じ
- 画像は保存しない。顔の特徴だけを保存し、コマンドで消せる。成長に合わせて覚え直せる
- カメラと首は `rover-core` の調停に従い、優先度の高い機能が動くときは止まる
- 下流の機能へ、汎用のカメラの機能（動きの量、静止画、映像のフレーム）を出す。下流の都合は入れない
- あいさつの判定（いつ、誰に、何と言うか）は、偽の検出結果を使って PC でテストできる

## Approach
`rover-core` の機能として登録し、カメラと首の資源を持つ。検出と認識はポートにし（実機は OpenCV、テストは偽物）、あいさつの判定は純粋なロジックにする。カメラの機能は、ほかの機能が使える口として出す。

## Scope
- **In**:
  - カメラの管理（起動、停止、上下の反転）
  - 顔の検出と追従（首、LCD の目）
  - 顔の認識、登録、削除
  - あいさつの判定と発話、あいさつの時間帯
  - カメラの機能の提供（動きの量、静止画、映像のフレーム）
  - 確認用の CLI（追従の確認、動きの量の表示）
  - self-check の項目（カメラ、モデル）
- **Out**:
  - USB カメラ（C270）の映像（`remote-control`）
  - だるまさんの判定（`daruma-game`）

## Boundary Candidates
- カメラと首の管理
- 検出・追従・認識
- 顔の特徴の保存と削除
- あいさつの判定
- カメラの機能の提供

## Out of Boundary
- ゲームやラジコンの振る舞い
- 映像の配信（`remote-control`）

## Upstream / Downstream
- **Upstream**: `rover-core`（機能を足す口、首のサーボ、声、LCD、保存）
- **Downstream**: `daruma-game`（動きの量）、`remote-control`（静止画・映像のフレーム）

## Existing Spec Touchpoints
- **Extends**: なし
- **Adjacent**: `daily-routine`（おやすみモード中はカメラを止める）

## Constraints
- 顔の特徴は生体情報。リポジトリに入れず、外部に送らない
- モデルのライセンス: YuNet（MIT）、SFace（Apache 2.0）。表記を README に残す
- YuNet 2023mar は OpenCV 4.8 以上が必要で、OpenCV 5 では動かない。実機は apt の OpenCV 4.10（Trixie）、CI は `opencv-python-headless>=4.10,<5` にそろえる（5.x にするなら 2026may モデルに替える）
- picamera2 は CI で読み込めない（libcamera が必要）。実機用のアダプタの中だけで読み込む
