# Brief: conversation

## Problem
子どもは、ロボットとおしゃべりしたい。保護者は、子どもに安全な話し方をしてほしい。名前などの個人情報を外部に送らず、使いすぎないよう制限したい。

## Current State
サンプルの `chat.py` に、次の振る舞いがある。
- **会話**:
  - 聞いた言葉を Claude API に送り、返事を声で話す
  - 30 秒以内にボタンを押すと、続けて話せる
- **子ども向けのシステムプロンプト**（日本語）:
  - 返事は 1〜2 文
  - 個人情報を聞かない・覚えない
  - 怖い話を避ける
  - けがや危険があれば大人に伝えるよう促す
  - 親に秘密にすることを勧めない
  - ロボットであることを認める
- **名前の扱い**: 子どもの名前は送らない。モデルは `{name}` と書き、ロボットの中で名前を差し込む
- **制限**:
  - 時間帯（07:00〜21:30）
  - 1 日の回数上限（60 回）
- **失敗時**: 拒否されたときや通信エラーのときは、やさしく言い直す
- **API キー**: リポジトリの外（`~/.config/osekkai/env`）に置く

見つかっている問題:
- 1 日の回数上限がメモリだけにあり、再起動で元に戻る。聞き取れなかった回も数えている
- 返事の音声が、キャッシュに無期限に残る
- 一部の予期しない例外で、処理全体が落ちる
- API の呼び出し方（モデル名、effort、beta の fallback）が今も有効かを確認していない

## Desired Outcome
- 子どもから見た振る舞い（聞いて、短く、やさしく返す。続けて話せる）はサンプルと同じ
- `voice-gateway` で他の機能に当てはまらなかった言葉を受ける
- 子どもの名前を外部に送らない。会話の記録を保存しない。返事の音声を残さない
- 時間帯と 1 日の上限は、再起動しても守られる
- API の失敗や拒否のときも、ロボット全体は止まらず、やさしく返す
- 会話の流れと制限は、偽の LLM を使って PC でテストできる

## Approach
`voice-gateway` の「当てはまらない言葉の受け手」として登録する。LLM の呼び出しはポートにする（実機は Anthropic SDK、テストは偽物）。API の呼び出し方は、設計の段階で claude-api のスキルを使って最新の仕様を確認する。1 日の上限は `rover-core` の保存の仕組みで残す。

## Scope
- **In**:
  - 会話の流れ（続けて話す、終わり方）
  - システムプロンプトと名前の差し込み
  - 時間帯と 1 日の上限（再起動しても残す）
  - 失敗と拒否の扱い
  - API キーの置き場所と読み込み
  - 個人データの扱い
  - self-check の項目（API キーがあるか）
- **Out**:
  - 音声の聞き取りと振り分け（`voice-gateway`）
  - 会話からほかの機能を呼ぶこと（振り分けは `voice-gateway` が行う）

## Boundary Candidates
- LLM クライアントのポート
- 会話のセッション管理
- 安全対策（プロンプト、名前、ログ）
- 利用上限

## Out of Boundary
- 言葉の振り分け
- 声の合成（`rover-core`）

## Upstream / Downstream
- **Upstream**: `rover-core`（声、LCD、保存）、`voice-gateway`（言葉の受け取り、続けて聞く）
- **Downstream**: なし

## Existing Spec Touchpoints
- **Extends**: なし
- **Adjacent**: `voice-gateway`

## Constraints
- 公開リポジトリ。API キーはリポジトリに入れない
- 相手は 4 歳前後の子ども
- API の呼び出し方（技術構成の確認より。設計の段階で claude-api のスキルで改めて確かめる）:
  - `claude-opus-5-5`、`output_config={"effort": "low"}`、beta の `server-side-fallback-2026-07-01` と `fallbacks="default"` の組み合わせは、今も有効
  - Python SDK が `fallbacks` を引数として受け付けない場合は、`extra_body` で渡す
  - `thinking` の無効化、`temperature` などは 400 になるので渡さない。`stop_reason == "refusal"` を先に確かめる
