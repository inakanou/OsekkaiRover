# Requirements Document

## Project Description (Input)
子どもは、ロボットとおしゃべりしたい。保護者は、子どもに安全でやさしい話し方をしてほしい。子どもの名前などの個人情報を外部に送らず、使いすぎないよう時間帯と回数を制限したい。

今は、サンプルの `chat.py` が、聞いた言葉を Claude API に送り、子ども向けのシステムプロンプト（1〜2 文、個人情報を聞かない、怖い話を避ける、ロボットであることを認めるなど）で返事を声で話している。子どもの名前は送らず、ロボットの中で差し込んでいる。1 日の回数上限がメモリだけにあって再起動で元に戻る、聞き取れなかった回も数える、返事の音声がキャッシュに無期限に残る、一部の例外で処理全体が落ちる、などの問題がある。

`rover-core` の機能として conversation（おしゃべり）を作る。`voice-gateway` で他の機能に当てはまらなかった言葉を受け、子どもから見た振る舞い（聞いて、短く、やさしく返す。続けて話せる）はサンプルと同じにする。名前を外部に送らず、会話の記録と返事の音声を残さず、時間帯と 1 日の上限は再起動しても守る。API の失敗や拒否のときもロボット全体は止まらず、やさしく返す。会話の流れと制限は偽の LLM で PC でテストできるようにする。詳しくは `.kiro/specs/conversation/brief.md` を参照。
