## Implementation Notes
- texts は gate より下の層なので、`texts.GATE_REPLIES` のキーは文字列（"not_set_up"・"clock_unsynced"・"out_of_hours"・"limit"）。2.4 の `GateReason` は同じ値の文字列の列挙（StrEnum）にし、全員が表のキーで、キーの集まりが列挙と同じことをテストする
- `SYSTEM_PROMPT` の目印は文字の `{name}` で書いてある。2.1 で `NAME_MARK in texts.SYSTEM_PROMPT` をテストする。`SYSTEM_PROMPT` に `.format()` をかけない
- `call_name_variants` は空や空白だけの項目も通る。2.1 の置き換えでは空や空白だけの項目を飛ばす
- `Turn` は ports.py にある（アダプタは ports と texts しか読めないため）。2.2 の session.py は ports から読み込み、定義し直さない
- `shape_reply` は「。」だけの返事を「。」のまま返す（空にしない）。4.1 では、整えた後に文字（かな・漢字・英数字）が残らない返事も空とみなして `SAY_EMPTY` を話す
- `Session.touch(now)` を足した（確認で見つかった穴）。4.1 では拒否・空・失敗を話し終えたら `touch` を呼ぶ。呼ばないと、前の返事から 130 秒で、続けて聞いている間でもやりとりが消える
- `DailyUsage.load` はファイルを読まない。初めての `reached(today)`・`add_one(today)` で読む。この 2 つには門が確かめた（時刻が確かな）日付だけを渡す。同期の前に読むと、古い日付を読めなかった日にしてしまうため（確認で 2 回差し戻された）
- `check_gate` の `usage_reached` は真偽の値なので、4.1 では `synchronized and usage.reached(today, limit)` のように、時刻が確かなときだけ `reached` を呼ぶ。時刻が確かでない間に `usage.json` を読まないテストを足す。`now` は地方時の datetime を渡す
- `ClaudeChatModel(credential)` の引数の名前は credential（名前に key を入れない決まり）。4.3 の手順書に「`ANTHROPIC_LOG=debug` にすると SDK が送る中身をログに出すので使わない」と書く
- 言い終えた返事・拒否は、話している途中の中断や、話し終えた後の静かな状態・止める旗があっても 1 回数える（要件 5.4。費用の上限を守るため）。設計の手順 5 の一文を要件に合わせて直した。やりとりには足さず、続けて聞くも頼まない
- 会話の AI は初めて使うときに 1 回だけ選び、鍵がない（None）も覚えたままになる。4.3 の手順書に「鍵を置いたら再起動する」と書く
