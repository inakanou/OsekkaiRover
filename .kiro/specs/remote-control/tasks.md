- [x] 2.4 (P) 走行の判定を作る

  - 前に進む命令では、1 回の読みで、前の物（決めた距離より近い）・段差（どれかの床の値が基準以下。設定で無効にできる）・読めない値のどれでも止め、危険の種類を返す。危険が続く間は前に進まず、後退は受け付ける。物がない印は安全とする

  - 危険の声は 10 秒に 1 回までにする
  - 偽の時計と台本の読みで、すべての止まり方・後退の制限・声の間隔のテストが通る

## Implementation Notes
- 1.1: パッケージの中の向き（adapters/* は ports だけ、checks が読める部品）は、そのモジュールを作るタスクで test_remote_import_direction.py に足す
- 1.2: 引用符のない数の pin（pin: 1234 など）は空の pin になる（安全側）。7.1 の remote.setup の理由と 7.3 の手順書で「引用符で囲んだ 4〜8 けたの数字」と案内する
- 1.2: Availability から知らせの文を引く表（texts.MESSAGES）は 2.3 で足す
- 1.3: FakeLease.preempt は on_preempt を呼んだスレッドで直ちに呼ぶ（基盤は別のスレッド）。中断の受け手でロックを取る部品のテストは、ロックを持たない所から preempt() を呼ぶ。偽物は基盤の後始末（止める・首を戻す）を覚えないので、calls に stop や home を期待しない
- 2.2: 全体のテストで tests の test_routine_trial.py の「短い時間で押さなければスキップまで進み…」が 1 回だけ落ち、回し直すと通った（時間に左右される既存のテスト。この機能の外）
- 2.3: 知らせの文の表は availability.MESSAGES と message_for（OK は None）。service と web はこちらを使う
- 2.4: 走行の判定は止まる側に倒す: 命令の時刻が今より先・NaN、後退を始めた時刻が今より先、far の印のない無限の距離は止める。前に進む命令は後退の印も解く（前を押す＝後ろを離した）
- 2.6: 写真の保存先は photos.default_photo_dir(paths)。名前は Clock.now() の壁の時刻で、prune にも Clock.now() を渡す
- 3.1: HatSensors(clock=...) は clock が要る（feature と cli で渡す）。実機で確かめること: ADC の 1 回の i2c_rdwr の読み方、lgpio の gpio_trigger・gpio_read・gpio_get_chip_info・alert と callback（ns の時刻）、基盤が開いている gpiochip をもう一度開けるか、sysfs に label があるか。30 ms で下がらないときは gpio_read で echo がまだ高いときだけ far
- 3.2: 実機の OpenCV 4.10 は CONVERT_RGB=0 で (1, N) の uint8 を返し、C270 の JPEG に DHT はない（実機で確かめた）
- 3.1: 基盤が HAT の MCU を起こし直した直後（起動・止めるとき）の約 1 秒、ADC は 2 回とも同じでたらめの高い値（2571・3085・3599）を返した。bus を開いてから 2 秒は床を読めない（危険）とする
- 4.1: OperatorSlot.claim は自分で席を空にしない。service は 0.5 秒ごとの tick で expire() を呼び、真なら走行を止める。ログインが切れたら drop(token) で、真なら走行を止める
- 4.2: LeaseKeeper.want は、低い優先度（見つけてあいさつ）が NECK を持っていると、取り上げの猶予で最長 2〜3 秒止まることがある。走行の 0.1 秒の繰り返しの中では呼ばない。中断でない取り上げ（revoke）では on_lost を呼ばないので、首のカメラは want の戻りの段でも返す
- 4.3: 中断の知らせでは、may_borrow を偽にしてから FrameHub.release_neck() を呼ぶ（LeaseKeeper の lost→on_lost の順）。段が NONE に下がったときと revoke のときも release_neck を呼ぶ。FrameHub.tick() は feature の 0.5 秒の繰り返しから呼ぶ。読み途中の release_neck の後、最大 1 秒は前の 1 枚が配られうる（後で世代の番号で直してよい）
