# Brief: remote-control

## Problem
子どもは、スマホやタブレットからロボットを走らせて遊びたい。保護者は、家の中だけで安全に使え、使える時間を決められ、日課の声かけを邪魔しないことを求めている。

## Current State
サンプルの `remote.py`（Flask、ポート 8080）に、次の振る舞いがある。
- **アクセスの制限**:
  - 家のネットワーク（プライベートアドレス）からだけ開ける
  - 4 けた以上の pin でログインする。再起動すると、ログインし直しになる
- **操作**:
  - 矢印ボタンを押している間だけ走る（最後の命令から 0.5 秒で止まる）
  - 首の操作、ブッブー、ダンス、速さの切り替えがある
- **走行の安全**:
  - 前に物があるとき（超音波）は前に進まない
  - 段差（床センサー）でも前に進まない
  - 止まるときに声と LCD で知らせる
- **映像と写真**:
  - 首のカメラと USB カメラ（C270）の映像を表示する。映像は保存しない
  - 「しゃしん」で 2 台のカメラの写真を撮り、リポジトリの外に保存する
- **話させる**: 文字を入れると話す。最大 120 文字で、話した言葉の音声とログは残さない
- **使える時間**:
  - 時間帯を決められる
  - 1 日の上限（分）を決められる
  - 日課の声かけ・予告・おしゃべりが始まると止まる
  - おやすみモード中は使えない

見つかっている問題:
- 後退は、センサーで確かめていない
- 1 日の上限がメモリだけにあり、再起動で元に戻る。ページを開いているだけで時間が減る
- ログインの失敗の待ち時間が、並列のリクエストでは効かない
- 英数字以外の pin を入れると、内部エラーになる
- ダンスが、停止の命令で止まらない
- 話す声と LCD 表示が、日課の声と衝突する
- 写真が無期限に残る

## Desired Outcome
- 子どもから見た遊び方（押している間だけ走る、映像を見る、写真を撮る、話させる）はサンプルと同じ
- 走行は常に安全側に倒す:
  - 命令が途切れたら止まる
  - 前進も後退も、危険を検知したら止まる
  - 例外が起きたら止まる
  - 優先度の高い機能が始まったら止まる。ダンスも止まる
- 家の外からは使えない。ログインは総当たりに強い
- 使える時間と 1 日の上限は、再起動しても守られる。上限は実際に操作した時間で数える
- 写真は一定期間で整理できる
- 走行の安全判定・時間の計算・ログインの規則は、偽のセンサーと時計を使って PC でテストできる

## Approach
`rover-core` の機能として登録する（日課より低い優先度を申告する）。Web の画面と API はアダプタ、走行の安全判定と時間の計算は純粋なロジックにする。首のカメラの映像は `presence` の口から、USB カメラはこのスペックで扱う。

## Scope
- **In**:
  - Web の画面と API
  - ログインとアクセスの制限
  - 走行（押している間だけ動く、安全判定、速さ）
  - 首の操作
  - ブッブーとダンス
  - 映像の配信（首のカメラは `presence` から、USB カメラはここで扱う）
  - 写真の保存と整理
  - 話させる機能
  - 使える時間と 1 日の上限
  - 超音波と床センサー
  - self-check の項目（ポート、pin の設定）
- **Out**:
  - 家の外からの操作
  - 通信の暗号化（家の Wi-Fi に限定することで代える。必要なら後で検討）

## Boundary Candidates
- アクセスの制限とログイン
- 走行の安全判定
- 利用時間の管理
- 映像と写真
- 話させる機能

## Out of Boundary
- 首のカメラの管理（`presence`）
- 資源の調停の仕組み（`rover-core`）

## Upstream / Downstream
- **Upstream**: `rover-core`（モーター、サーボ、声、LCD、保存、調停）、`presence`（首のカメラの静止画とフレーム）
- **Downstream**: なし

## Existing Spec Touchpoints
- **Extends**: なし
- **Adjacent**: `daily-routine`（優先度が上で、始まるとラジコンが止まる）

## Constraints
- pin はリポジトリに入れない
- 家の Wi-Fi の中だけで使う
- 相手は子ども。安全を最優先にする
